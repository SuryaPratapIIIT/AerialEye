# 06 - UI/UX Polish

## Design Principles Applied
- **Dark Mode Aesthetic**: UI utilizes dark grays, slate, and cyan accents (`bg-[#0a0d14]`, `text-slate-400`, `text-cyan-400`).
- **Consistent Layout**: Centralized header bar with left-aligned breadcrumbs and primary actions on the right.
- **Micro-Animations**: Framer Motion used for smooth tab transitions, panel expansions, and route changes.
- **Empty States**: Friendly empty states with Lucide React icons guiding users to the next action (e.g., "Search for imagery and click Analyze").
- **Quality Indicators**: Clear badging for metadata (`REAL`, `HEURISTIC`, `DEMO`) and confidence levels.
- **Responsive**: Grid layouts collapse to single columns on small screens.
